Student Management System

This workspace contains a Spring Boot backend and an Angular frontend scaffold under `week-7`.

Backend:
- Path: `week-7/backend`
- Run:
```bash
cd week-7/backend
mvn spring-boot:run
```
- H2 console: http://localhost:8080/h2-console (JDBC URL: `jdbc:h2:mem:students`)

Frontend:
- Path: `week-7/frontend`
- Run:
```bash
cd week-7/frontend
npm install
npm start
```
(This uses Angular CLI — install globally if needed.)
